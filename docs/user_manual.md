# 校园文明能量站系统用户手册

## 1. 系统概述

校园文明能量站是一个基于 Web 的校园管理系统，旨在通过积分激励机制促进学生文明行为，实现学生行为管理、积分管理、评价管理等功能。系统支持多角色登录，包括学生、教师和管理员，各角色拥有不同的权限和功能。

## 2. 系统登录

### 2.1 登录界面
- 打开浏览器，访问系统地址（默认为 http://localhost:8080）
- 系统会自动跳转到登录页面
- 输入用户名和密码
- 点击登录按钮

### 2.2 默认账号
| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | admin | admin123 |
| 教师 | teacher | teacher123 |
| 学生 | student | student123 |

### 2.3 登录后跳转
- 管理员：跳转到管理员系统概览页面
- 教师：跳转到教师工作台页面
- 学生：跳转到学生个人信息页面

## 3. 学生端使用指南

### 3.1 个人信息
- **功能**：查看个人基本信息和积分情况
- **操作**：登录后自动显示在首页
- **信息包括**：姓名、班级、积分总数

### 3.2 积分记录
- **功能**：查看积分变动历史记录
- **操作**：点击左侧菜单的"积分记录"选项
- **记录内容**：积分变动值、类型（奖励/扣除）、原因、时间

### 3.3 评价查看
- **功能**：查看教师对自己的评价
- **操作**：点击左侧菜单的"评价查看"选项
- **评价内容**：评价维度、评分、评价内容、评价时间

### 3.4 商城兑换
- **功能**：使用积分兑换商品
- **操作**：点击左侧菜单的"商城兑换"选项
- **兑换流程**：选择商品 → 确认兑换 → 扣除积分

## 4. 教师端使用指南

### 4.1 工作台
- **功能**：查看班级学生统计信息
- **操作**：登录后自动显示在首页
- **统计内容**：学生总数、今日积分变动、待评价学生数

### 4.2 学生管理
- **功能**：管理班级学生信息
- **操作**：点击左侧菜单的"学生管理"选项
- **功能包括**：
  - **查看学生列表**：显示所有学生信息
  - **添加学生**：点击"添加学生"按钮，填写学生信息
  - **编辑学生**：点击学生信息后的"编辑"按钮
  - **删除学生**：点击学生信息后的"删除"按钮

### 4.3 积分管理
- **功能**：管理学生积分
- **操作**：点击左侧菜单的"积分管理"选项
- **功能包括**：
  - **积分操作**：选择学生，输入积分值和原因，点击"添加"或"扣除"
  - **积分记录**：查看所有学生的积分变动记录

### 4.4 评价系统
- **功能**：对学生进行多维度评价
- **操作**：点击左侧菜单的"评价系统"选项
- **评价流程**：选择学生 → 选择评价维度 → 输入评分和评价内容 → 点击"提交"

### 4.5 数据统计
- **功能**：查看班级积分统计和评价分布
- **操作**：点击左侧菜单的"数据统计"选项
- **统计图表**：班级积分排名、积分趋势、评价分布

## 5. 管理员端使用指南

### 5.1 系统概览
- **功能**：查看系统运行状态和统计数据
- **操作**：登录后自动显示在首页

- **操作**：点击左侧菜单的"用户管理"选项
- **功能包括**：
  - **查看用户列表**：显示所有用户信息
  - **添加用户**：点击"添加用户"按钮，填写用户信息
  - **编辑用户**：点击用户信息后的"编辑"按钮
  - **删除用户**：点击用户信息后的"删除"按钮
  - **重置密码**：点击用户信息后的"重置密码"按钮

### 5.3 角色管理
- **功能**：管理系统角色
- **操作**：点击左侧菜单的"角色管理"选项
- **功能包括**：
  - **查看角色列表**：显示所有角色信息
  - **添加角色**：点击"添加角色"按钮，填写角色信息
  - **编辑角色**：点击角色信息后的"编辑"按钮
  - **删除角色**：点击角色信息后的"删除"按钮

### 5.4 权限管理
- **功能**：管理系统权限
- **操作**：点击左侧菜单的"权限管理"选项
- **功能包括**：
  - **查看权限列表**：显示所有权限信息
  - **添加权限**：点击"添加权限"按钮，填写权限信息
  - **编辑权限**：点击权限信息后的"编辑"按钮
  - **删除权限**：点击权限信息后的"删除"按钮

### 5.5 系统配置
- **功能**：配置系统基础参数
- **操作**：点击左侧菜单的"系统配置"选项
- **配置包括**：
  - **基本配置**：系统名称、版本、描述
  - **安全配置**：登录超时时间、密码最小长度、验证码设置
  - **备份配置**：备份频率、保留天数

### 5.6 数据统计
- **功能**：查看系统级别的数据统计和分析
- **操作**：点击左侧菜单的"数据统计"选项
- **统计图表**：用户分布、登录趋势、积分分布、系统性能

## 6. 常见问题

### 6.1 登录问题
- **问题**：登录失败
  **解决**：检查用户名和密码是否正确，确保大小写正确
- **问题**：忘记密码
  **解决**：联系管理员重置密码

### 6.2 功能问题
- **问题**：无法添加学生
  **解决**：检查是否有添加学生的权限
- **问题**：无法进行积分操作
  **解决**：检查学生信息是否正确，确保积分值输入正确
- **问题**：无法查看统计数据
  **解决**：检查是否有查看统计数据的权限

### 6.3 系统问题
- **问题**：系统响应缓慢
  **解决**：检查网络连接，刷新页面
- **问题**：页面显示异常
  **解决**：清除浏览器缓存，刷新页面
