# 优化教师班级编辑与班级编号自动匹配

## Summary

本次改动解决两个问题：
1. **Bug 修复**：管理员端编辑教师用户的"绑定班级"区只显示"暂无可选班级"，必须先点开"班级管理" tab 才能加载班级列表。
2. **编号优化**：将班级新建/编辑对话框从"手填完整名称+手填编码"改为"年级下拉 + 班号输入"，系统自动生成 `name`、`grade_code`、`class_code`，并打通后端存储链路（当前后端 GET/POST/PUT 均未处理 `grade_code`/`class_code` 字段）。

**具体改动**：

gradeToCode(grade) {
    const map = { '高一': '01', '高二': '02', '高三': '03', '初一': '07', '初二': '08', '初三': '09' };
    return map[grade] || '';
},
buildClassName(grade, classNo) {
    if (!grade || !classNo) return '';
    return `${grade}(${classNo})班`;  // 如 "高二(1)班"
},
classNoToCode(classNo) {
    const n = parseInt(classNo, 10);
    return isNaN(n) ? '' : String(n).padStart(2, '0');
}
```

async addClass() {

    }
    const payload = {
        name: this.buildClassName(this.newClass.grade, this.newClass.classNo),

// 年级名→两位编码映射
std::string grade_to_code(const std::string& grade) {
    if (grade == "高一") return "01";
    if (grade == "高二") return "02";
    if (grade == "高三") return "03";
    if (grade == "初一") return "07";
    if (grade == "初二") return "08";
    if (grade == "初三") return "09";
    return "";
}
// 班号数字→两位编码
std::string classno_to_code(int class_no) {
    char buf[4];
    snprintf(buf, sizeof(buf), "%02d", class_no);
    return std::string(buf);
}
```

string grade_code = req_json.value("grade_code", "");

// 兜底
if (grade_code.empty() && !grade.empty()) {

if (class_code.empty()) {

## Assumptions & Decisions

1. **编号格式**：两位零填充（高一→01，1班→01），与现有种子数据 `student-02-01-05` 格式一致。用户已确认。
2. **实现位置**：前端实时预览 + 后端兜底。用户已确认。
3. **输入方式**：拆分为"年级下拉 + 班号数字输入"。用户已确认。
4. **年级范围**：支持高一/高二/高三 + 初一/初二/初三（覆盖中学场景）。其他年级（小学、大学）留空，不影响使用。
5. **班级名称格式**：保持 `${grade}(${classNo})班`，如"高二(1)班"，与种子数据格式一致。
6. **编辑教师班级 bug 修复方式**：在 `openEditUser`/`openAddUser` 中按需 `await loadClasses()`，而非在 `mounted` 预加载（避免不必要的请求）。
7. **向后兼容**：后端兜底逻辑用正则从旧格式名称提取班号，确保旧数据编辑时也能补全编码。
8. **不改动**：`generate_user_id`（`models.cpp`）、学生 ID 生成逻辑、`teacher_classes` 表结构——这些已正常工作，不在本次范围。
